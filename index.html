Open Word documents online

Word Viewer opens .docx files directly in your browser. Read the document with its headings, lists, tables and images, jump through it with the contents, search for words and save it as PDF, web page, Markdown or plain text. Free, no account, nothing to install.

  • Private Your file never leaves your device. Everything runs locally in your browser.
  • Layout Headings, lists, tables, images, links and footnotes are shown as in Word. Switch between page view and a plain reading view.
  • Edit Change text, headings, lists and tables, then download the result as a Word document. Everything you do not change stays as it was.
  • Navigate Jump to any heading from the contents and find words in the whole document.
  • Convert Save as PDF, web page, Markdown or plain text, or copy the text to paste it anywhere.

Frequently asked questions

How do I open a Word file without Word?

Drag the .docx file onto this page or click “Choose file”. The document opens right away.

Is my file uploaded?

No. Your file is read and processed only in your browser. No data is sent to a server.

How do I convert a Word document to PDF?

Open the document and click “Print / PDF”. In the print window, choose “Save as PDF” as the printer.

Can I edit a Word document here?

Yes. Click “Edit”, make your changes and click “Download .docx”. Text, formatting, paragraph styles, lists, links and tables can be edited. Parts that are not shown, like headers and comments, stay in the file unchanged.

Can I open old .doc files?

No. Only .docx files, the format Word uses since 2007. Open a .doc file in Word or LibreOffice and save it as .docx first.

Does the document look exactly like in Word?

Close, but not exactly. Text, headings, lists, tables, images, links and footnotes are shown. Pages break where the document has a page break; headers, footers and comments are not shown.
